# The Dog Ate My Homework: Funniest Excuse

[![make.fun](https://img.shields.io/badge/make.fun-bounty-blue)](https://make.fun)
[![Node.js](https://img.shields.io/badge/Node-22-green)](https://nodejs.org)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Entry for the make.fun bounty **The Dog Ate My Homework: Funniest Excuse** — one line, under 200 characters, of the excuse a dog gives after being caught eating the homework.

## Run

```sh
node main.ts
```

The program writes the one-line excuse to `/output/entry.txt` and prints it to stdout.
